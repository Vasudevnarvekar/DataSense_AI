# 🚀 DataSense AI - Intelligent Data Analyst Agent

An AI-powered data analytics platform that combines traditional data analysis, AutoML, and Large Language Models (LLMs) into a single intelligent assistant.

DataSense AI allows users to upload datasets, clean data, perform exploratory analysis, generate visualizations, train machine learning models, execute SQL and Python code, and interact with the dataset using natural language.

---

# 🎯 Project Objectives

- Automate the complete data analysis workflow
- Build an AI assistant capable of understanding datasets
- Reduce manual effort in EDA and reporting
- Integrate LLMs into data analytics
- Learn modern AI engineering and agent workflows

## 🧩 LangGraph Multi-Agent Workflow

Current Architecture

```
                User

                  │

                  ▼

            Streamlit UI

                  │

                  ▼

             LangGraph

                  │

             Router Node

        ┌─────────┴─────────┐

        ▼                   ▼

 Summary Agent        Chat Agent

        │                   │

        ▼                   ▼
```
